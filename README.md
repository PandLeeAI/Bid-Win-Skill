## ✨ 它是什么

Bid-Win-Skill 是一个**招投标 / 政府采购领域**的专业智能体技能（Skill）。它以"资深评标专家"的视角为你：

- 解答招投标、政府采购任何法规、流程、风险问题；
- 解析你提供的**招标文件**，输出专家级《招标文件重点解读报告》；
- 解析你提供的**投标文件**，做**资格审查 → 符合性审查 → 模拟评分**，输出《模拟评标报告》。

一句话：**帮你把标书"看得比对手更透、比自己更稳"**。

---

## 🚀 两种工作模式

| 模式 | 你做什么 | 它产出什么 |
|---|---|---|
| **问答模式** | 直接问问题（如"联合体投标怎么认定？""什么情形必须公开招标？""质疑期限几天？"） | "结论 + 法条依据 + 风险提示"，并标注依据可信度 |
| **文件模式** | 上传招标文件（PDF/Word）→ 再上传投标文件 | 招标文件解读报告；投标模拟评标报告（逐项审查 + 模拟打分 + 优化建议） |

> 两种模式共用同一套权威知识库与引用机制，**先检索、后回答**，绝不凭记忆编条款。

## 🛡️ 为什么信它（核心卖点）

- **不幻觉、有依据**：内置 15 部现行法规离线知识库。任何条款结论都必须回到 `Doc/` 原文核对条号，没有依据就直说"依据不足"，绝不编造。
- **三档依据标注**：【依据充分】/【依据有限】/【依据不足】，让你一眼判断结论的可靠程度。
- **2026-10 已做一轮法规有效性核验**：剔除失效/废止版本，确保引用**现行有效**。重庆 2025 新条例、新专家库办法、新评标办法已全部入库。
- **覆盖全面**：
  - 国家层面：招标投标法 + 实施条例、政府采购法 + 实施条例、87/94/74 号令、评标委员会规定；
  - 重庆地方：招标投标条例（2025 修订）、综合评标专家库办法（2025）、评标方法规定（2025）、电子招投标办法（2021）、投诉处理实施细则（2021）。
- **离线即用**：知识库随包携带，无网也能精准引用；必要时自动联网核验官方最新来源。

## 📦 怎么用

### 方式一：本地目录直接启用
1. 用 任意Agent 打开本项目根目录（即含 `SKILL.md` 的目录）；
2. 在技能入口导入 / 启用 `bid-win-skill`；
3. 在对话中说 **"招投标咨询 / 评标专家 / 政府采购 / 帮我看这份标书 / 模拟评标"** 等，技能自动触发。

### 方式二：导入发布包
1. 取 `dist/Bid-Win-Skill.zip`；
2. 在 任意Agent 「技能」中导入该 zip 即可启用，无需额外配置。

### 调用示例
- 问答：`政府采购公开招标数额标准是多少？`
- 文件：`（上传某项目招标文件.pdf）帮我做一份专家视角的重点解读`
- 文件：`（再上传投标文件.docx）按上面招标文件做资格审查和模拟评分`
