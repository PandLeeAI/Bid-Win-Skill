# 评标流程清单（文件模式复用模板）

> 本文件供"文件模式"使用：导入招标文件后做专家视角解析；导入投标文件后做模拟评标。
> 所有核对结论须注明"依据：招标文件条款X / 法规条款Y"，不得凭印象判定。

---

## 一、招标文件重点解读报告（仅导入招标文件时输出）
按以下结构输出，突出"评标专家视角"的重点关注项与风险点：
1. **项目概况**：采购人/招标人、项目类型（工程/货物/服务）、预算或最高限价、采购/招标方式、标段划分。
2. **投标人资格要求**：资质等级、业绩要求、财务/社保/纳税、人员（项目经理/负责人）、设备能力等；逐一列出审查要点与证明材料清单。
3. **实质性要求与废标/无效投标条款**：集中摘录招标文件中标"★"或"不得""否决""无效"的条款，列成清单。
4. **评标办法与评分细则**：评标方法（经评审最低价/综合评估）、各评分模块权重、价格分计算公式（低价优先法？）、加分/扣分项、否决项。
5. **关键时限**：招标文件发售期（≥5日）、投标截止、开标、答疑/澄清截止、中标候选人公示（≥3日）、合同签订（30日）、异议（招标文件10日前/开标现场/公示期）、投诉（10日/30工作日）。
6. **合同主要条款与风险点**：付款、工期/交货期、质保、违约责任、履约保证金（≤10%）。
7. **专家提示（重点关注）**：易踩坑处（如资格条件与项目无关、指定品牌、评标基准价机制、低于成本判定、同品牌代理商、联合体限制等）。

---

## 二、资格审查核对清单（导入投标文件后逐项）
> 依据：招标文件"投标人须知/资格要求" + 法规（01-第26条、02-第34条、11-第22条、13-第20条等）。
- [ ] 独立承担民事责任能力（营业执照/法人证明）— 是否有效、与投标主体一致。
- [ ] 商业信誉与财务会计制度（审计报告/财报/银行资信）— 是否满足。
- [ ] 依法纳税和社保（纳税证明、社保缴纳证明）— 是否齐全、期限符合。
- [ ] 资质/资格等级（建筑业企业资质、行政许可等）— 等级与范围是否覆盖项目。
- [ ] 业绩要求（中标通知书/合同/验收）— 数量、金额、时间是否达标，是否弄虚作假。
- [ ] 人员要求（项目经理注册证/职称/社保）— 是否到位、是否存在挂靠。
- [ ] 设备/技术能力（设备清单/技术证明）— 是否满足。
- [ ] 无重大违法记录声明（参加前3年）— 声明与信用核查。
- [ ] 关联关系/利害关系（单位负责人同一、控股管理、与招标人利害）— 02-第34条、03-第19条。
- [ ] 联合体（如有）：共同投标协议、资质就低、成员不重复投标 — 01-第31条、02-第37条。
- [ ] 同品牌代理商限制（货物）— 03-第19条、87号令相关规定。
- 结论：逐项判定"通过/不通过"，不通过者说明依据与后果（资格不符→否决，02-第51条③、04-第22条）。

---

## 三、符合性审查（实质性响应）核对清单
> 依据：02-第51条、04-第23/25条、13-第20/36条、11-第36条。
- [ ] 投标文件签署盖章（单位盖章+负责人签字）— 04-第25条②、02-第51条①。
- [ ] 投标有效期（是否满足招标文件要求）。
- [ ] 投标保证金（是否提交、金额≤2%、形式、基本账户转出）— 02-第26条、13-第17条。
- [ ] 报价（是否超预算/最高限价、是否低于成本需说明）— 02-第51条⑤、04-第21条。
- [ ] 工期/交货期/服务期（是否超期）— 04-第25条③。
- [ ] 技术规格/质量标准（是否实质响应）— 04-第25条④。
- [ ] 实质性条款（招标文件"★"项）— 是否全部响应。
- [ ] 联合体协议（如适用）— 02-第51条②。
- [ ] 无串通/弄虚作假/行贿（40/41/42条、13-第36条）。
- [ ] 附加招标人不能接受的条件 — 04-第25条⑥。
- 结论：存在重大偏差（未实质响应）→ 否决；细微偏差可要求补正（04-第26条）。

---

## 四、模拟评分清单
> 严格按招标文件"评分细则"逐项打分；本清单为通用框架，实际以招标文件为准。
- [ ] 价格分：按招标文件公式（低价优先法/基准价）计算，核对计算口径。
- [ ] 技术分：技术方案、施工组织/实施方案、人员配置等，按细项打分并留痕。
- [ ] 商务分：业绩、奖项、认证、售后等，核证明材料与打分对应。
- [ ] 加分/扣分项：是否重复计分、是否在细则范围内。
- [ ] 客观分复核：资格审查、否决、得分统计等客观性项，按10-第35条可复核。
- 输出：得分明细表（模块—分值—得分—依据），预估得分区间，扣分/风险说明。

---

## 五、模拟评标报告（导入投标文件后输出）
1. **综合结论**：是否通过资格审查与符合性审查；预估得分/排名区间；是否推荐为中标候选人（定性，非决定性）。
2. **资格审查结果**：通过/不通过项及依据。
3. **符合性审查结果**：否决/重大偏差/细微偏差及依据。
4. **模拟评分明细**：各模块得分与扣分理由。
5. **风险点**：废标/扣分/投诉隐患（如资格条件瑕疵、低于成本、串标嫌疑）。
6. **优化建议**：针对投标文件可补强之处（须合法合规，不得教唆造假）。
7. **免责声明**：模拟结果仅供参考，以评标委员会及主管部门认定为准；本技能不替代法律意见。

---

## 六、投标文件 vs 招标文件 一一核对映射
导入两文件时，建立映射表：招标条款（资格/实质性/评分项）→ 投标响应位置/内容 → 是否满足 → 依据。重点核对：资格条件逐条对应、实质性条款逐条响应、评分项逐条举证、偏差逐条列示。
